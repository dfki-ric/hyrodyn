Detailed Description

Parallelograms or parallelogram-chains can be modeled in HyRoDyn using the concept of mimic joints in the URDF file.

A code snippet of mimic joint tag

definition is shown below:
<joint name=PASSIVE_JNAME type=JTYPE >
<parent link=PARENT >
<child link=CHILD >
<origin xyz=COORDS rpy=ANGLES >
<axis xyz=DIRECTION >
<mimic joint=ACTIVE_JNAME multiplier=m offset=b >
</joint>
HyRoDyn will collect the multiplier and offset values from the URDF and transfers them to the loop closure function of the mechanism.



where M is the multiplier matrix containing m (+1, -1, 0 as its entries) and B is the offset vector containing b (0s or angular offset, in rad) involved with the active joint frame.
